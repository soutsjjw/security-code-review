# 正式發布簽核清單

- [ ] **資安主管**：70 項控制目標、Pass/Fail 判定標準及替代控制政策核准。
- [ ] **法遵／個資窗口**：法規適用主體與法條施行狀態核對；個資控制措辭核准。
- [ ] **制度負責人**：公司密碼、MFA、資料分級、加密、備份、日誌保留門檻核准。
- [ ] **維運／網管**：IdP、Proxy、IIS、容器、網路控制責任界線及證據取得方式核准。
- [ ] **系統負責人**：針對 Web/API/Batch/Mobile 各種典型專案，完成適用性矩陣範例。
- [ ] **資安稽核人員**：抽測多個系統，記錄重大誤報／漏報，覆核風險嚴重度校準。
- [ ] **標準管理員**：正式 Web 參考指引 v3.2 控制條號逐條核對完成。
- [ ] **標準管理員**：ASVS 對照表覆核；未確定的映射不得標記 verified。
- [ ] **發布管理員**：版本、批准人、核准日、生效日、變更紀錄及滾動檢討週期記錄完成。
- [ ] **工具負責人**：所有 70 項結果 schema 驗證成功、證據及例外檢查正常。
