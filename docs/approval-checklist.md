# 發布後治理建議（非規則集發布門檻）

**核心 70 項規則集 v2.0.0 已為正式版**，不需要先取得公司資安核定；此清單僅供組織自行採用時評估流程、責任與風險，不是安裝、執行或發版的先決條件。

- [ ] **資安管理人員**：確認各系統適用範圍、例外風險與代替控制是否有證據。
- [ ] **法遵／個資窗口**：按受測機關或系統情境確認實際適用法規與法定責任。
- [ ] **制度負責人**：核對密碼、MFA、資料分級、加密、備份、日誌保留等本地政策（若系統適用）。
- [ ] **維運／網管**：確認 IdP、代理層、IIS、容器、網路與動態測試等外部證據。
- [ ] **系統負責人**：記錄 Web／API／Batch 等個別專案的適用性與核定分級資訊。
- [ ] **審查者**：覆核高風險 Finding、避免無證據 Pass、避免把指引映射當成全面符合。
- [ ] **維護者**：執行規則／Schema／HTML／JSON 驗證並記錄版號與變更摘要。

這份檢核表**不是強制簽核表**。規則集正式版不代表受測系統已取得法規合規、第三方測試或單位核定。
