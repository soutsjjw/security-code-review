## 測試方式

在 Skill 根目錄執行：

```bash
python scripts/validate_package.py
python -m unittest discover -s tests -v
```

測試重點包括主規則 JSON/YAML 與分類清單一致性、固定 70 個 ID、報告 Schema、證據及例外處理、缺失情境、HTML／JSON 產出以及新規範清冊。

**此摘要列的是檢核範圍與應執行的測試，非宣稱本次變更已在執行環境全部通過。** 要合併發行前，仍須以實際測試記錄確認。結構驗證不等於曾對任何個別系統執行滲透測試或取得法遵認證。
