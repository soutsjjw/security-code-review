## 共通判定準則

- **Pass／符合**：適用要求已以實證完成；僅靠找不到問題、關鍵字未命中或理論設計不足以判符合。
- **Fail／不符合**：適用條件成立、存在可驗證不符且已評估部署層或外部等效控制。
- **Review／待確認**：缺少完整程式碼、部署、測試、營運或政策證據。
- **N/A／不適用**：確定功能及相關義務均不適用，需逐項記錄具體理由。
- 風險高低由實際影響面評估，不以 Fail 項數或檢核類別推定。
- 法定例外／免執行不等於 N/A；應另有核准、風險接受及法定程序紀錄。

## 70 項逐條定義

## AC：存取控制（Access Control）

### AC-01 Session 逾時自動失效

- **控制目標**：控制閒置與絕對存取期間
- **適用**：有互動式登入、Session 或具有有效期限的存取憑證
- **不適用前提**：無登入、Session 或存取憑證，且不存在等效工作階段
- **審查重點**：Session/Cookie/JWT 過期時間；逾時後重新鑑別測試
- **符合（Pass）**：有效期限由伺服端驗證且逾期不可使用
- **不符合（Fail）**：逾期憑證或 Session 仍可存取受保護資源
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：驗證設定、逾期測試、登入流程
- **人工確認**：逾時長度是否符合組織政策
- **改善方向**：設定伺服端逾時與重新驗證
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-7.3.1, v5.0.0-7.3.2（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-02 登出後 Session 立即銷毀

- **控制目標**：確保登出後相關工作階段失效
- **適用**：系統提供登出、工作階段結束或憑證撤銷功能
- **不適用前提**：沒有使用者 Session、登出流程或需撤銷之憑證；須說明架構
- **審查重點**：登出與撤銷流程；舊 Token/Session 重放
- **符合（Pass）**：相關憑證依風險與明訂政策無法繼續使用或有經核准的短效替代策略
- **不符合（Fail）**：登出後可持續使用原應立即失效的有效憑證
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：登出流程、Token 設定、重放測試
- **人工確認**：JWT 短效與撤銷政策是否可接受
- **改善方向**：導入 Token 撤銷、短效 Token 或權限版本驗證
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-7.4.1（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-03 管理介面存取來源限制

- **控制目標**：限制管理入口的未授權來源
- **適用**：存在管理介面或高權限管理 API 且有正式來源管制要求
- **不適用前提**：無管理入口；如改由等效控制實施，需驗證其符合性，不能直接列為不適用
- **審查重點**：管理路由與身分管理；VPN/零信任/Proxy/來源政策
- **符合（Pass）**：滿足正式管理來源管制政策且有可驗證控制
- **不符合（Fail）**：明訂必須限制來源而實際沒有防護
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：管理路由、網路架構、Proxy/防火牆設定
- **人工確認**：替代控制與實際網路部署
- **改善方向**：依政策採可信網段、VPN 或身分感知存取控制
- **判定注意**：IP 白名單非所有系統必然強制；先確認管理入口政策及身份感知的等效控制。
- **ASVS 5.0.0 對應**：v5.0.0-8.4.2（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-04 最小權限原則

- **控制目標**：落實最小權限
- **適用**：系統具有身分、角色、授權資源或服務帳號
- **不適用前提**：完全不存在可區分的權限資源，且有架構證據
- **審查重點**：角色權限矩陣；服務帳號權限；預設拒絕政策
- **符合（Pass）**：角色及服務僅取得必要權限且預設拒絕
- **不符合（Fail）**：過度授權、未驗證即取得高權限
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：授權政策、權限矩陣、權限測試
- **人工確認**：業務職責及必要權限基準
- **改善方向**：收斂權限、建立角色及資料範圍矩陣
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-8.2.1（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-05 Process 以一般使用者權限執行

- **控制目標**：避免服務以過高系統權限執行
- **適用**：部署執行環境有作業系統身分與權限
- **不適用前提**：不包含任何可控之服務執行身分且已界定責任
- **審查重點**：AppPool/Container/Service 執行身分；主機權限與部署帳號
- **符合（Pass）**：執行身分符合最小系統權限需求
- **不符合（Fail）**：應用程式不必要地以系統管理員或 root 執行
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：部署設定、服務帳號、容器映像設定
- **人工確認**：主機實際執行身分
- **改善方向**：改用專用非特權身分及最小 ACL
- **判定注意**：只能從原始碼推測最低權限；Pass 須檢視實際執行身分及權限。
- **ASVS 5.0.0 對應**：待正式逐條核對（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-06 遠端存取授權過濾

- **控制目標**：驗證遠端存取的授權與來源要求
- **適用**：系統提供遠端存取功能、API 或管理入口
- **不適用前提**：未提供任何遠端服務
- **審查重點**：外部 API 保護鏈；來源/身分/用途限制
- **符合（Pass）**：遠端請求依契約完成身分與存取驗證
- **不符合（Fail）**：缺少必需的授權條件而可存取敏感功能
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：Endpoint、Middleware、Handler、部署網路規則
- **人工確認**：來源 IP 是否為正式控制要求
- **改善方向**：集中執行存取控制並建立測試
- **判定注意**：不可將缺少 API 來源 IP 白名單直接判缺失；應依介接契約/系統風險決定。
- **ASVS 5.0.0 對應**：v5.0.0-8.3.1（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A01:2025（建議分類，非合規要求）

### AC-07 目錄瀏覽限制

- **控制目標**：防止非授權目錄與檔案列示
- **適用**：系統提供 Web 靜態資源、檔案下載或檔案目錄存取
- **不適用前提**：未提供檔案或目錄列示、下載服務
- **審查重點**：Static File/Directory Browsing；Web Server 靜態檔案設定
- **符合（Pass）**：敏感資料夾不可列示且無法直接讀取
- **不符合（Fail）**：可列出或直接下載非公開檔案
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：Web Server 設定、StaticFiles、實測 URL
- **人工確認**：實際部署的目錄瀏覽功能
- **改善方向**：停用目錄瀏覽並隔離私有檔案
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-13.4.3（已列項為相關要求，非完整等價）

### AC-08 垂直/水平越權防護

- **控制目標**：防止同層與跨角色資源越權
- **適用**：存在需按使用者、角色、組織、租戶或資源歸屬授權的資料操作
- **不適用前提**：系統沒有資源歸屬／角色隔離需求，附明確資料流證明
- **審查重點**：路由識別碼與資源歸屬；Repository/SQL 查詢隔離；跨帳號測試
- **符合（Pass）**：每個受保護資源均實施伺服端物件層級授權
- **不符合（Fail）**：只靠登入或前端控制且可讀寫他人資源
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：完整授權呼叫鏈、查詢條件、反例測試
- **人工確認**：跨機關授權例外是否正式核准
- **改善方向**：在服務端檢查 Owner、Scope、Tenant
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。

## AU：身分鑑別與認證（Authentication）

### AU-01 密碼強度規範

- **控制目標**：維持本地密碼建立安全性
- **適用**：系統自行受理或驗證使用者密碼
- **不適用前提**：全部密碼由外部身分提供者管理，本系統不承擔密碼政策
- **審查重點**：密碼建立/更改政策；長度及封鎖已洩漏密碼措施
- **符合（Pass）**：適用的密碼政策符合組織正式要求
- **不符合（Fail）**：實際使用的密碼驗證弱於已核准政策
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：Identity 設定、驗證器、註冊測試
- **人工確認**：純 SSO 系統由 IdP 承擔的責任
- **改善方向**：採用現代密碼政策並阻擋洩漏密碼
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-6.2.5, v5.0.0-6.2.9（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A07:2025（建議分類，非合規要求）

### AU-02 密碼定期更換與歷史檢查

- **控制目標**：控管密碼更換與歷史使用要求
- **適用**：系統管理本地密碼且正式政策訂有密碼生命週期要求
- **不適用前提**：不管理本地密碼，或正式規範不要求該特定輪替控制
- **審查重點**：密碼更換條件；憑證洩漏應變；經核定的更換政策
- **符合（Pass）**：符合經核准的密碼生命週期政策
- **不符合（Fail）**：違反明確要求或遭洩漏仍無重設處置
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：密碼管理設定、政策文件
- **人工確認**：週期強制更換不宜無條件套用；確認 IdP 政策
- **改善方向**：依風險採洩漏觸發重設、歷史限制
- **判定注意**：不預設強制週期性密碼變更；以適用政策、洩漏風險與安全指引核定的更換條件為準。
- **ASVS 5.0.0 對應**：待正式逐條核對（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A07:2025（建議分類，非合規要求）

### AU-03 帳號鎖定機制

- **控制目標**：降低暴力破解與憑證猜測
- **適用**：系統具有可被嘗試猜測的認證／Token 驗證流程
- **不適用前提**：無此類流程；外部 IdP 負責時需取得繼承控制佐證
- **審查重點**：猜密碼與憑證填充保護；節流/封鎖/風險式偵測
- **符合（Pass）**：驗證端點具有效防自動化攻擊控制
- **不符合（Fail）**：可無限制高頻驗證且缺乏替代防護
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：登入/Token 端點、節流設定、負向測試
- **人工確認**：IdP 或 WAF 是否代管控制
- **改善方向**：加強限速、風險偵測與告警
- **判定注意**：不以無限制帳號鎖定為唯一措施，須評估 DoS 及節流等替代控制。
- **ASVS 5.0.0 對應**：v5.0.0-6.1.1（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A07:2025（建議分類，非合規要求）

### AU-04 身分鑑別資訊不以明文傳輸

- **控制目標**：保護認證憑證傳輸
- **適用**：系統傳輸認證資料、Token、Cookie 或其他認證秘密
- **不適用前提**：無認證秘密傳輸
- **審查重點**：登入與 Token 傳輸；TLS 端到端設定
- **符合（Pass）**：憑證只經受保護通道傳輸
- **不符合（Fail）**：帳密或 Token 可透過明文鏈路傳送
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：HTTPS/HSTS/TLS 設定、傳輸流程
- **人工確認**：Proxy 終止 TLS 後內網鏈路
- **改善方向**：強制安全傳輸並避免 URL 傳遞 Token
- **判定注意**：檢核要求須以核定適用矩陣、風險情境和控制責任判定；不得單以工具警示定性。
- **ASVS 5.0.0 對應**：v5.0.0-12.2.1（已列項為相關要求，非完整等價）
- **OWASP 2025 風險分類**：A07:2025（建議分類，非合規要求）

### AU-05 CAPTCHA 機制

- **控制目標**：抑制高風險端點自動化濫用
- **適用**：存在須防範自動化濫用的公開或匿名入口，且政策或風險分析要求保護
- **不適用前提**：無需要此防護的端點，或風險接受經正式核准
- **審查重點**：匿名/申請/驗證碼端點；限速、Bot 偵測或 CAPTCHA 等效控制
- **符合（Pass）**：符合風險政策且有 CAPTCHA 或可驗證等效機制
- **不符合（Fail）**：受保護端點未採任何被要求的反自動化措施
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。

## CR：加密機制與傳輸安全（Cryptography）

### CR-01 機敏資料傳輸加密

- **控制目標**：保護機敏資料在傳輸途中的機密性
- **適用**：機敏資料跨程序、主機、網路或服務傳輸

- **審查重點**：外部 TLS 與反向 Proxy；資料庫/內部 API/SMTP 加密
- **符合（Pass）**：所有適用機敏傳輸採足夠保護
- **不符合（Fail）**：機敏資料經明文鏈路或不驗證伺服器憑證
- **待確認（Review）**：缺少必要的程式碼、部署、測試或制度證據；不以關鍵字未命中推定符合。
- **證據要求**：傳輸設定、網路拓樸、連線設定
- **人工確認**：實際 TLS 組態與內部服務鏈路
